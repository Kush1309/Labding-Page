## Responsive Behavior

### Desktop (> 968px)
- All sections full width
- Multi-column layouts maintained
- Navbar with center navigation

### Tablet (768px - 968px)
- Grid layouts reduce columns
- Some sections stack
- Navbar remains horizontal

### Mobile (< 768px)
- Single column layouts
- Hamburger menu
- Stacked buttons
- Touch-friendly spacing
- No horizontal scroll

## Animation & Interaction

1. **Navbar:** Sticky with shadow on scroll
2. **Hero:** Fade in up animation
3. **Cards:** Lift on hover (translateY -5px to -10px)
4. **Buttons:** Color change + lift + shadow
5. **Dropdown:** Fade in down animation
6. **Gallery:** Overlay slide up on hover
7. **Forms:** Border color change on focus
8. **Mobile Menu:** Slide in from left

All animations: 0.3s ease timing
Respects: prefers-reduced-motion
